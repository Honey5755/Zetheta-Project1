# Submission & Repository Transfer Protocol

This project is **strictly private and confidential** and remains the property of
Zetheta Algorithms Private Limited. Per the brief, submission is the **transfer of
this private repository to `@ZethetaIntern`**, done between **Day 15 and Day 30** of
the project window.

## Pre-transfer checklist

- [x] All 8 steps implemented and end-to-end navigable.
- [x] `npm run lint` — zero errors.
- [x] `npm run test:unit` — all tests pass.
- [ ] `npm run test:e2e` — run on a machine where the Cypress runner can launch.
- [ ] `README.md` screenshots added (capture each step at mobile + desktop).
- [x] (Bonus) Deployed to Netlify: https://zethetaproject1.netlify.app/ (URL in `README.md`).

## Repository settings (do these in GitHub UI — account-owner actions)

1. **Visibility:** confirm the repo is **Private**.
2. **Disable forking:** Settings → General → uncheck "Allow forking".
3. **Branch protection:** Settings → Branches → add a rule for `main`
   (require pull request before merging; no force pushes).
4. **No public wikis/discussions:** Settings → General → Features → disable Wikis
   and Discussions.
5. **Collaborators:** add only authorised collaborators. Do **not** add anyone
   else.

## Transfer ownership to `@ZethetaIntern`

1. GitHub → repo → **Settings → General → Danger Zone → Transfer ownership**.
2. Enter the new owner: **`ZethetaIntern`**.
3. Confirm by typing the repository name.
4. Once `@ZethetaIntern` accepts, the transfer is complete and the project is
   considered **submitted**.

> Note: the certificate is issued after 15 days from the start date or on repository
> transfer, whichever is later (max 30 days from start).

## Platform upload (Zetheta WorkBridge)

The project page also has a file-upload slot. The binding submission is the repo
transfer above; for the platform slot, attach a short cover document (project title,
private repo URL, summary, and — if deployed — the live URL). A separate
**feedback video** (1–5 minutes, face visible, describing the project) can be added
via the platform's Feedback section to improve shortlisting chances.
